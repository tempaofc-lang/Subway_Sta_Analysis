# 当前分析假设与扩展规则

本版本按用户2026-10-04最新指示执行。

1. 暂不考虑目的地门禁、临时道路封闭与地铁入口临时关闭；选定的地图入口在计算情景中视为可使用。
2. 仍保留路网结构形成的绕行与路径缺失。入口字段不完整、无路线、端点偏移异常等是数据未知，不由条件假设消除。
3. 统一计算通勤起点/目的地入口 → 所选地铁站各基础入口的步行最短路线。大学校门作为学生在校外的通勤接驳代表点；校内从宿舍到校门的距离不计入，也不能据此估计学生实际全程通勤。
4. 居民区与大学门口分别归组，其他办公/教育/医疗目的地保留其用途；不以POI数量估计人口。原类别中托育和医美应显示实际对象名称。
5. 所有地图与数字来源于确定性路线结果。主情景4.5 km/h，敏感性3.5 km/h；10/15分钟阈值。API返回时间仅作独立字段，不与固定步速时间混合。
6. 扩展技术门槛：至少95%的路线满足正距离、非空折线、端点偏移≤60米及折线长度检查；每个样本有效/未知状态分别记录。模型检查通过后可扩展情景，不再将现场门禁核验设为本轮前置条件。
7. 新站选取用于功能与区位的案例比较，样本数量与类型可能不均衡，报告同时显示分组样本数。整体比例仅描述所选样本，不能外推总体。
8. 分析输入与发布 JSON 保持高德来源 GCJ-02 坐标。参考底图使用 OpenStreetMap；渲染时将 GCJ-02 近似逆转换为 WGS84，再统一投影到 Web Mercator，避免不同坐标系直接叠加。转换仅用于显示，不改变路线距离、步行时间或覆盖判定；非测绘级纠偏。地图不得表述为连续等时圈或实际开放服务范围。
9. 居民区与办公等主样本以站点中心周边1公里为候选范围；学生校门代表点允许至1.5公里并单列扩展筛选标记。大学中心与校门位置分开处理，不能用中心在圈外自动排除近站校门。南昌航空大学本轮父入口约1043米，纳入学生扩展组；名称为北门的公交POI不当作校门。

10. 第二轮新增奥体中心、谢家村、双港；只对新增样本复核POI主类型、过滤兼类商户和非高校机构，既有六站保留历史快照。同一校园可与不同站点配对；跨站样本数不等于独立校园数或人口数。

11. 全网阶段按113个去重目录站点分批导入；换乘站可归属多条线路。独立标记待采集、无入口、无合格样本、失败与部分路线待核查，均不以缺数据判不可达。目录运营核验不等于出入口现场开放确认。

12. 全网新增站允许精确父ID、150501主类型与站名均匹配的明确非编号入口；纯出口不默认可进站。原试点选定入口保持历史条件。采样分页依据原始响应页长，不能将类别过滤后的短列表视为请求末页。
